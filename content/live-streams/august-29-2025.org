* Let's Check Out Some Terminal Tools!

Just for fun, today we're going to check out some terminal-based applications that might overlap with things you can do in Emacs:

- [[https://profanity-im.github.io/][Profanity]]: XMPP client
- [[https://github.com/jarun/nnn/][nnn]]: File browser
- [[https://cmus.github.io/][cmus]]: Music player
- [[https://github.com/aristocratos/btop][btop++]]: System monitor

One goal is to try and set these up to work well in the Foot terminal and maybe wire them into a Sway environment to call them up quickly or pin them to workspaces.
