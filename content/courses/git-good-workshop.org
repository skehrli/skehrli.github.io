* Get Good at Git!

Have you used Git for a while but still feel like you don't really understand what you're doing?  Do you wish you understood how Git /really/ works under the hood?  Wish you knew all the cool techniques that the expert hackers use?

"Git Good" is a one-day live workshop that intends to teach you many of the secrets of expert Git users within 4 hours while giving you hands-on exercises to try it all for yourself!

This workshop is meant for those who have used Git at a basic or intermediate level but it should also be quite informative for more advanced users who feel they have some gaps in their Git knowledge.

Here is a sample of the topics we will cover:

- Unlocking the Git conceptual model: commits, hashes, and refs
- Discovering what Git stores locally
- Understanding remotes and how to use them effectively
- Understanding merge vs rebase, when to use them, and how to resolve conflicts
- Cleaning up commits with amends and interactive rebase
- Fixing commit mistakes with `git reset` and `git cherry-pick`
- ... and other best practices for working with Git repositories in professional and open source projects!

* What's Included

- 4 hours of focused instruction on Git fundamentals, concepts, and practical use cases
- Hands-on exercises during the course of the workshop so that you get to try everything yourself
- A take-home workshop guide that covers all of the important material you will learn
- A Git cheat sheet which gathers together all of the important commands into a concise document
