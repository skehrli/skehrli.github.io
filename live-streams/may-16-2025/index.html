¶Let’s finish out the game jam the best we can!

We’ve been working on a MUD (multi-user dungeon) game using Guile Scheme, Spritely Goblins, and Datastar for the last week. We didn’t make quite as much progress as we hoped, but it was still a great time.

In this stream we’ll just try to finish whatever we can to make the game playable and have some fun crafting.
