¶Packaging Guix for Void Linux

Today we’re going to try and package Guix for Void Linux. It has been tried before, but never got merged.

We’ll try to carry forward the efforts already made by others to get Guix packaged for Void and see what we can learn along the way.

Existing work:

  • Guile 3: https://github.com/void-linux/void-packages/pull/27320
  • Guix: https://github.com/void-linux/void-packages/pull/22359

You can check out my personal package fork here:

https://github.com/daviwil/void-packages/
