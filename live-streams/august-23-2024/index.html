¶Checking out Casual Suite

Today we’re going to check out the “Casual” packages for Emacs by Charles Choi. These packages are intended to provide friendly interfaces for certain Emacs functionality so that they are easier to navigate.

https://github.com/kickingvegas/casual-suite

Here are the (currently) included Casual interfaces:

  • Casual I-Search - a Transient menu for I-Search.
  • Casual Dired - a Transient porcelain for the Dired file manager.
  • Casual Info - a Transient porcelain for Info.
  • Casual Calc - a Transient porcelain for Calc.
  • Casual IBuffer - a Transient porcelain for IBuffer.
  • Casual RE-Builder - a Transient porcelain for RE-Builder.
  • Casual Bookmarks - a Transient porcelain for the bookmark list.
  • Casual Avy - a Transient porcelain for Avy.

We may actually install and configure these separately, though!
